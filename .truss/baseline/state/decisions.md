# Decisions

> Decided decisions. D-NNN, sequential, never reused. **One decision per entry** — if the title needs an "and" or a semicolon, it is two entries; a bundled entry cannot be revised in part later.
> Roughly one line each for `Decision:` / `Rationale:` / `Consequences:` — this file is boot context, read every session. Design detail and the story of the work belong in the owning domain file or git, linked from here.
> Never delete an entry: supersede it, and only with the human's go-ahead. An entry binds until then — but it is evidence, not scripture: when it meets the challenge test, open an `OD-NNN` and add `Challenged-by:` here (AGENTS.md §3).
> Entry grammar: docs/conventions.md.
